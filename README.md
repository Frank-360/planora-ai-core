# Planora AI Core

Planora AI Core is an open-source project that provides the foundational structure and prompt systems used in Planora AI, an AI-powered platform designed to improve learning outcomes for children by supporting teachers in generating high-quality lesson notes.

## What This Repository Contains
- Lesson structure templates for standardized lesson delivery
- Sample AI prompts for lesson generation
- Frameworks for curriculum-aligned content creation

## Purpose
This project aims to promote transparency, collaboration, and innovation in AI-powered education tools, especially in low-resource environments.

## Impact
By improving lesson structure and delivery, Planora AI helps ensure that children receive clearer, more engaging, and effective learning experiences.

## Open Source Commitment
We are committed to continuously expanding this repository to support developers, educators, and organizations working to improve education through technology.
